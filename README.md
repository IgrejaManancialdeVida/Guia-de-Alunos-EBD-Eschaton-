# Eschaton — Hub do Aluno com 39 lições

Este pacote unifica os três volumes em um único `index.html`, seguindo a estrutura do hub do professor.

Arquivos principais:
- `index.html`: hub do aluno com 3 volumes e 39 lições.
- `manifest.json`: PWA atualizado para 39 lições.
- `navegacao.js`: navegação local para alternar entre os volumes no hub.
- `capa-revista.html`, `capa-revista.png`, `icon-192.png`, `icon-512.png`: ativos normalizados.

Padrão dos links das lições:
- Volume I: `v1-licao-01.html` até `v1-licao-13.html`
- Volume II: `v2-licao-01.html` até `v2-licao-13.html`
- Volume III: `v3-licao-01.html` até `v3-licao-13.html`

Para funcionar sem links quebrados, renomeie ou publique os arquivos das lições seguindo esse padrão na mesma raiz do `index.html`.
